# Verilog Labs

A collection of Verilog modules and exercises for learning and practicing FPGA design class.

## 📁 Contents

- **bcd** – Binary-Coded Decimal counters  
- **bcd_up_down** – Up/down BCD counters  
- **pwm** – Pulse Width Modulation examples  
- **uart** – UART transmitter/receiver modules  
- **robotarm** – Control logic for robotic arm projects  
- **password** – Simple password/security logic  
- **challenge / exam** – Practice exercises and test problems
