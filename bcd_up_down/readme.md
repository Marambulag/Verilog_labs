Prueba de contador en FPGA con Quartus y Verilog

📌 Descripción

Este proyecto implementa y prueba un contador en un FPGA utilizando Quartus y Verilog. 
⚙️ Requisitos

Quartus Prime (Intel FPGA)

FPGA compatible (Ejemplo: Cyclone IV, MAX10)

Cable de programación JTAG

📂 Estructura del Proyecto

/gates_project

│── counter_div.v # Módulo principal con compuertas lógicas

│── counter_div_tb.v # Testbench para simulación

│── bcd_up_down.qpf # Archivo del proyecto en Quartus

│── bcd_up_down.qsf # Archivo de configuración del FPGA

│── README.md # Este archivo
