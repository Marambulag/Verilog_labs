Prueba de pwm en FPGA con Quartus y Verilog

📌 Descripción

Este proyecto implementa y prueba un pwm en un FPGA utilizando Quartus y Verilog.
⚙️ Requisitos

Quartus Prime (Intel FPGA)

FPGA compatible (Ejemplo: Cyclone IV, MAX10)

Cable de programación JTAG

📂 Estructura del Proyecto

/gates_project

│── pwm.v # Módulo principal con compuertas lógicas

│── pwm_tb1.v # Testbench para simulación

│── pwm.qpf # Archivo del proyecto en Quartus

│── pwm.qsf # Archivo de configuración del FPGA

│── README.md # Este archivo
