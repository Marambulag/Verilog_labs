Prueba de Compuertas Lógicas en FPGA con Quartus y Verilog

📌 Descripción

Este proyecto implementa y prueba 7 segment display en un FPGA utilizando Quartus y Verilog.

⚙️ Requisitos

Quartus Prime (Intel FPGA)

FPGA compatible (Ejemplo: Cyclone IV, MAX10)

Cable de programación JTAG

📂 Estructura del Proyecto

/gates_project

│── bcd.v # Módulo principal con compuertas lógicas

│── bcd_tb.v # Testbench para simulación

│── bcd.qpf # Archivo del proyecto en Quartus

│── bcd.qsf # Archivo de configuración del FPGA

│── README.md # Este archivo
