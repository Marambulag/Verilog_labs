Prueba de uart en FPGA con Quartus y Verilog

📌 Descripción

Este proyecto implementa y prueba uart en un FPGA utilizando Quartus y Verilog.
⚙️ Requisitos

Quartus Prime (Intel FPGA)

FPGA compatible (Ejemplo: Cyclone IV, MAX10)

Cable de programación JTAG

📂 Estructura del Proyecto

│── top_loopback.v # Módulo principal con compuertas lógicas

│── rxtx_tb.v # Testbench para simulación

│── uart.qpf # Archivo del proyecto en Quartus

│── uart.qsf # Archivo de configuración del FPGA

│── README.md # Este archivo
