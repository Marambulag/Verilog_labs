Prueba de robotarm en FPGA con Quartus y Verilog

📌 Descripción

Este proyecto implementa y prueba un brazo robot con pwm en un FPGA utilizando Quartus y Verilog.
⚙️ Requisitos

Quartus Prime (Intel FPGA)

FPGA compatible (Ejemplo: Cyclone IV, MAX10)

Cable de programación JTAG

📂 Estructura del Proyecto

│── vga_acelerometro.v # Módulo principal con compuertas lógicas

│── Accelerometer.qpf # Archivo del proyecto en Quartus

│── Accelerometer.qsf # Archivo de configuración del FPGA

│── README.md # Este archivo
